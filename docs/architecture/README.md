`noesi-cpa` prototype and the phase-by-phase porting notes written while v2
was being built. It is kept as an engineering record, not as guidance.

The current, authoritative description of the system is
**[`docs/ARCHITECTURE.md`](../ARCHITECTURE.md)**. Where these files disagree
with it or with the source code, they lose.
