# Golden bundles

Frozen input/output bundles captured from the noesi-cpa prototype (Phase 0),
one per procedure: inputs, mapping, coverage state, findings, refusals, and
limitations, plus pinned source digests of the prototype code that produced
them.

These bundles exist to prevent accidental semantic changes during the port —
they document current behavior, they do not bless its accuracy.

Capture runs in `../noesi-cpa`; results are committed here.
